## Instrucciones de uso
 ### 1.Descargar el repositorio
 ```bash
 git clone https://github.com/AitanaNB/Desarrollo-Web-SGSSI.git
 ```
### 2.Activar el servicio Docker en la carpeta
```bash
$ cd Desarrollo-Web-SGSSI
```
```bash
$ docker-compose up -d
```

### Para parar Docker
```bash
$ docker-compose stop
```
